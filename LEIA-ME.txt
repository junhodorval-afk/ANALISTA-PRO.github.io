ANALISTA FF — PACOTE INSTALÁVEL PARA ANDROID

O QUE ESTE ZIP ENTREGA
- Site preparado como PWA: pode ser instalado pelo Chrome Android e abrir como app, sem Play Store.
- Ícone, manifesto e cache básico offline.
- O arquivo index.html mantém o aplicativo original.

COMO PUBLICAR NO MESMO GITHUB
1. Extraia o ZIP.
2. Envie TODOS os arquivos desta pasta para a raiz do mesmo repositório GitHub Pages, substituindo o index.html antigo.
3. Aguarde o Pages publicar.
4. No Android, abra o endereço HTTPS do GitHub Pages no Chrome.
5. Menu ⋮ > “Instalar app” ou “Adicionar à tela inicial”.

IMPORTANTE SOBRE EMAILS E ADM
O HTML original guarda usuários e pedidos no localStorage do navegador. Isso significa que cada celular tem seus próprios dados: os e-mails e pedidos de liberação NÃO vão aparecer no ADM de outro aparelho. O botão de liberar campeonato existe no HTML, mas também depende desses dados locais. Este ZIP não finge resolver isso.

Para que o e-mail cadastrado apareça para o ADM em qualquer celular, é necessário ligar o app ao Firebase Authentication + Cloud Firestore e publicar regras de segurança. O arquivo firebase-config.example.js é apenas um modelo e ainda não ativa a sincronização. Não envie senha do Firebase nem chave privada.

SOBRE APK
Este pacote é instalável como aplicativo Android via Chrome, sem Play Store, mas NÃO é um arquivo .apk nativo. Gerar um APK real exige empacotar o projeto Android (por exemplo, Capacitor/Android Studio) e compilar/assinar.
